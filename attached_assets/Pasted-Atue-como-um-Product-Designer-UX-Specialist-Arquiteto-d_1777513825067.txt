Atue como um Product Designer + UX Specialist + Arquiteto de Sistemas e reestruture completamente o fluxo de PRIMEIRO ACESSO (onboarding), gestão de usuários e segurança do aplicativo.

OBJETIVO:
Criar um fluxo de entrada claro, obrigatório e inteligente para novos colaboradores, garantindo:
- preenchimento de dados
- leitura de documentos
- assinatura de termos
- definição de senha segura
- organização de dados por tags

Sem quebrar o sistema atual.

--------------------------------------------------
🚀 1. FLUXO DE PRIMEIRO ACESSO (ONBOARDING)
--------------------------------------------------

Criar um fluxo obrigatório para novos usuários ao entrar pela primeira vez.

Esse fluxo deve acontecer ANTES do acesso completo ao app.

📌 Etapas do fluxo:

1. Definir nova senha
- Usuário recebe senha padrão
- Obrigatório trocar no primeiro acesso
- Campo: nova senha + confirmação
- Regras de senha (mínimo, etc)

2. Dados pessoais
- Telefone (com máscara)
- Data de nascimento (aniversário)
- Possui filhos? (Sim/Não)
- Se SIM → Quantidade de filhos

3. Dados profissionais (com base em tags)
- Unidade / Local (dropdown)
- Setor (dropdown)
- Cargo (dropdown)

👉 Esses campos devem ser preenchidos pelo usuário
👉 Mas podem ser editados depois pelo admin

4. Documentação (Integra)
- Mostrar documentos obrigatórios
- Separar:
  - leitura
  - aceite
  - assinatura

👉 Bloquear avanço até:
- leitura concluída
- termos assinados

5. Confirmação final
- Mostrar resumo
- Botão “Finalizar cadastro”

--------------------------------------------------
🔒 2. CONFIGURAÇÕES DE SEGURANÇA (ADMIN)
--------------------------------------------------

Criar uma nova aba no painel admin:

👉 “Configurações de Segurança”

Nela deve ser possível:

- Definir senha padrão de primeiro acesso
- Definir regras de senha:
  - tamanho mínimo
  - obrigatoriedade de número/letra

- Configurar obrigatoriedade de:
  - troca de senha no primeiro login
  - preenchimento de dados

--------------------------------------------------
🔑 3. RESET DE SENHA (ADMIN)
--------------------------------------------------

No painel de usuários:

Adicionar opção:

👉 “Resetar senha”

Comportamento:
- Reseta para senha padrão definida
- Marca usuário como “precisa redefinir senha”
- Obriga passar pelo fluxo de onboarding novamente (opcional)

--------------------------------------------------
📧 4. MELHORIA DO SISTEMA DE CONVITE POR EMAIL
--------------------------------------------------

Reestruturar envio de convite:

📌 Ao criar usuário:
- Nome
- Email
- (Opcional) tags pré-definidas

📌 Sistema envia email com:
- Link de acesso
- Senha padrão
- Instrução clara de primeiro acesso

📌 Melhorias:
- Status do convite:
  - Enviado
  - Aberto
  - Concluído
- Reenviar convite
- Copiar link manual

- Seleção via dropdown (não texto livre)
